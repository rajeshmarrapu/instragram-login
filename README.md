# Instagram Login Page 

This project is a simple of the Instagram login page.  
It is built using **HTML** and **CSS**, mimicking the look and feel of the official Instagram login UI.

---

## 🚀 Features
- Responsive login form with **username** and **password** fields  
- Instagram logo at the top  
- "Log In" and "Log in with Facebook" buttons  
- "Forgot password?" and "Sign up" links  
- Minimalist UI design with centered login box
